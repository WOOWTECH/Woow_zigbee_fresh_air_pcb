# V4.0 上機驗收清單（Matter）

對象：分支 `rev/v4.0`。分三階段，前一階段全過才做下一階段：

| 階段 | 硬體 | 網路 | 目的 |
|---|---|---|---|
| A | ESP32-C6 開發板（LED 代替繼電器） | Wi-Fi 測試版＋本機 chip-tool | 資料模型、開關、感測器、下拉選單、互鎖、燈號、恢復出廠 |
| B | 同上 | Thread 正式版＋Thread 邊界路由器 | Thread 配對、HA／Apple／Google 實際顯示 |
| C | V3.4 打樣板 | Thread 正式版 | 真繼電器、市電、NFC、433 遙控、電源預算 |

每一項填「結果」欄：✅ 通過／❌ 失敗（寫實際看到什麼）／— 沒測（寫原因）。

## 0. 準備

### 0.1 開發板接線（板子設定 V3.3，與 V3.4 相同腳位）

| 功能 | GPIO | 開發板上怎麼接 |
|---|---|---|
| K1–K4 繼電器 | 6、7、0、1 | 各接一顆 LED＋330Ω 到 GND（高電位亮） |
| DI1–DI4 | 3、15、22、21 | 杜邦線，碰 GND＝接通（內建上拉） |
| 按鍵 B1 | 9 | 開發板的 BOOT 鍵 |
| 狀態燈 | 2 | 外接一顆 LED＋330Ω 到 GND（板上的 RGB 燈在 GPIO8，**不是**狀態燈） |
| 433 接收 | 23 | 不接（階段 C 才測） |
| NFC ST25DV | SDA 20、SCL 19 | 不接（log 會出現 NFC 初始化失敗，屬預期） |

### 0.1b 只用開發板本身（不接線）

`CONFIG_FA_DEVKIT_RGB=y`（Wi-Fi 測試版預設開；Thread 用 `sdkconfig.defaults.devkit`）時，板載 RGB 燈（GPIO8 WS2812）同時當狀態燈與 K1–K4 指示：
亮滅節奏＝狀態燈；顏色：全關暗白、K1 紅、K2 綠、K3 藍、K4 開時加白（變淡）。按鍵用板上的 BOOT。

```bash
idf.py -B build_thread_devkit -D SDKCONFIG=sdkconfig.thread_devkit \
  -D SDKCONFIG_DEFAULTS="sdkconfig.defaults;sdkconfig.defaults.devkit" -p /dev/ttyACM0 erase-flash flash monitor
```

### 0.2 這台電腦

```bash
# 帳號要在 dialout 群組（加入後要重新登入）
id -nG | tr ' ' '\n' | grep -x dialout
ls /dev/ttyACM* /dev/ttyUSB*
# chip-tool：Canonical snap v1.5.1 解包，不用 sudo；KVS 在 ~/esp/chip-tool-kvs
~/esp/chip-tool payload parse-setup-payload MT:Y.K9042C00KA0648G00
bluetoothctl list     # 要看得到藍牙控制器
```

### 0.4 配對資料（開發期測試值，每台都一樣）

| 項目 | 值 |
|---|---|
| VID／PID | 0xFFF1／0x8000 |
| 配對碼（passcode） | 20202021 |
| Discriminator | 3840（0xF00） |
| QR | `MT:Y.K9042C00KA0648G00` |
| 手動配對碼 | `34970112332` |

以上由 `~/esp/chip-tool payload generate-qrcode／generate-manualcode` 依韌體設定算出。

### 0.5 Endpoint 對照（依建立順序；開機 log 那行「Endpoint：插座 …」要和這張表一致）

| EP | 內容 | EP | 內容 | EP | 內容 |
|---|---|---|---|---|---|
| 1–4 | K1–K4 插座 | 9 | DI1 模式 | 10 | K1 模式 |
| 5–8 | DI1–DI4 接點感測器 | 11 | K1 點動時間 | 12–14 | DI2 模式／K2 模式／K2 點動時間 |
| | | 15–17 | 第 3 路，同上 | 18–20 | 第 4 路，同上 |

選項值：DI 模式 0 全關／1 按一次／2 持續；K 模式 0 自鎖／1 點動／2 互鎖；
點動時間 0–10 = 0.5 秒、1 秒、2 秒、5 秒、10 秒、30 秒、1 分、5 分、10 分、30 分、60 分。

出廠預設（`sdkconfig.defaults`）：三段風速＋1 路（K1–K3 互鎖、K4 自鎖）、DI 全部「持續」、點動 1 秒、同時吸合上限 4。

## 已知限制（不算失敗）

- 開發期用測試憑證，Apple／Google 會跳「未認證」。
- chip-tool 是 v1.5.1、裝置是 1.6 分支；若遇到只在 chip-tool 端出錯的情況，先改用 HA 或同版 chip-tool 確認。
- 換正式 VID 後，HA 不再讀 `ha_entitylabel`（白名單限制），要另外向 HA 送 PR。
