# WO_30109 新風控制器 V3.0 韌體（ESP32-C6）

ESP-IDF v5.5.4 ＋ esp-zigbee-lib v2（Espressif 自家 Zigbee 協定堆疊）。硬體見 [../README.md](../README.md)。

## 功能

| 功能 | 說明 |
|---|---|
| Zigbee 3.0 | **路由器**（市電供電，幫電池裝置中繼）。4 個端點 EP1–4，各是一個 *Mains Power Outlet*（On/Off 叢集）＝繼電器 1–4。Zigbee2MQTT／ZHA 會看到 4 個開關。 |
| 模式（指撥 S1） | 開機時讀一次，見下表 |
| 互鎖 | 風速群組內「先斷後通」：關掉舊的一檔 → 等 200ms → 吸合新的一檔。協調器同時要求兩檔時，後到的贏，前一檔自動關並回報 |
| 電源保護 | 同時吸合上限（預設 3）、兩顆線圈吸合間隔 ≥50ms、802.15.4 發射 +10dBm、不啟動 Wi-Fi |
| 433MHz 遙控 | SYN480R → IO23 邊緣中斷 → EV1527 解碼（連續兩幀相同才算）。學過的遙控器 A/B/C/D 鍵＝切換繼電器 1/2/3/4。最多記 8 支，存在 NVS |
| 按鍵 B1 | 短按：風速循環（關→1→2→3→關；4 路模式＝切換繼電器 1）。按住 3–8 秒放開：學習遙控器 20 秒。按住 ≥10 秒放開：恢復出廠 |
| 指示燈 L1 | 慢閃＝尚未入網；恆亮＝已入網；快閃＝學習模式（或按住 3–8 秒中）；按住超過 10 秒時恆亮＝放開就重置 |

### 指撥模式（S1：ON = 1）

| bit1 bit0 | 模式 | 互斥群組 | 典型接法 |
|---|---|---|---|
| 0 0 | 4 路獨立 | 無 | 4 個獨立負載 |
| 0 1 | 三段風速＋1 路 | 繼電器 1–3 | 1/2/3 = 低/中/高速，4 = 閥／加熱 |
| 1 0 | 兩段風速＋2 路 | 繼電器 1–2 | 1/2 = 低/高速，3、4 獨立 |
| 1 1 | 4 路互斥 | 繼電器 1–4 | 四段選擇 |

> 原設計 V1.3 的指撥定義沒有留下文件，上表是 V3.0 的新定義。

### 電源預算（為什麼預設值這樣設）

IRM-02-12 額定 12V 167mA，超過 110%（約 184mA）進保護。

| 負載 | 3.3V 側 | 換到 12V 側（降壓效率 88%） |
|---|---|---|
| ESP32-C6 802.15.4 收訊（路由器常態） | 73mA | 23mA |
| SYN480R＋LED＋其他 | ~9mA | 3mA |
| 4 顆 G5Q 線圈 | — | 133mA |
| **4 顆全吸，持續** | | **159mA（95%）** |
| 發射 +10dBm 峰值（毫秒級，規格書 0/+12dBm 內插 ≈174mA） | +~100mA | +~32mA |

**V3.1：PWM 降壓保持（預設開）。** 每顆線圈先全壓 `FA_RELAY_PULLIN_MS`（100ms，Omron 規定 ≥100ms），
之後用 LEDC 以 20kHz、60% duty 保持；D1–D4 續流（V3.1 改 B5819W），線圈平均 7.66V（額定 64%，Omron 要求 ≥30%），
12V 端每顆 33.3→14.4mA（`sim/relay_pwm_hold.cir`）。吸合錯開 110ms，同時最多 1 顆在全壓。

| 情況 | 12V 側 | 判定 |
|---|---|---|
| 4 顆保持＋發射峰值 | 26＋32＋4×14.4 ≈ 116mA | 額定 70% |
| 3 顆保持＋1 顆吸合＋發射峰值（最壞） | 26＋32＋3×14.4＋33.3 ≈ 135mA | 額定 81% |
| 關掉 PWM（V3.0 行為）：4 顆＋發射峰值 | 191mA | 超過 110% 保護點 → 上限 3 |

`FA_MAX_RELAYS_ON` 開 PWM 時預設 4、關掉時預設 3；關掉 PWM 卻設 4、或吸合間隔 ≤ 吸合時間，會直接**編譯失敗**（`main/app_main.c` 的 `#error`）。
標準版 G5Q-1 沒有 Omron 的 PWM 背書（只有 -PW 型有，JLC 無料），打樣要在最高環境溫度下實測保持與釋放。

## 建置

```bash
. ~/esp/esp-idf-v5.5.4/export.sh
cd firmware
idf.py set-target esp32c6     # 第一次
idf.py build
```

設定（`idf.py menuconfig` → *WO30109 新風控制器*）：同時吸合上限、發射功率、互鎖間隔、吸合間隔。

### 燒錄

P2 2×3 排針：1 3V3、2 GND、3 TXD0、4 RXD0、5 EN、6 BOOT(IO9)。接 USB-UART 轉接板（含 DTR/RTS 自動下載電路）就能直接燒；沒有自動電路時，按住 B1 再上電即進下載模式。

```bash
idf.py -p /dev/ttyUSB0 flash monitor
```

⚠️ **燒錄時不要接 230V**。板子低壓區與市電隔離，但轉接板和電腦接地會變成另一條路徑；要邊通市電邊看 log 請用隔離型 USB-UART。

## 單元測試（不需要 ESP-IDF）

純邏輯在 `components/fa_core/`（繼電器互鎖、EV1527 解碼、按鍵、遙控器表），用主機 gcc 加 AddressSanitizer／UBSan 測：

```bash
make -C firmware/test
```

CI 每次 push 都會跑單元測試，並用 `espressif/idf:v5.5.4` 容器編譯整個韌體。

## 尚未驗證（要打樣後做）

- 實際入網（Zigbee2MQTT／ZHA）、4 個端點命名與回報。
- 433 解碼對實際遙控器的相容性：只支援 **EV1527 學習碼**（市售 433 遙控器最常見）；PT2262 固定碼與滾碼遙控器不支援。按鍵對應假設 A/B/C/D = 0x8/0x4/0x2/0x1，部分品牌不同時要改 `fa_remote_key_to_channel()`。
- SYN480R 關閉靜噪（R14 = 0R）時 DO 腳會持續輸出雜訊，中斷量要實測；太高可改成 R14 不上件（開靜噪，靈敏度少 3dB）。
